# 本地生化反应网络仿真服务

对本地生化反应网络做导入、校验、确定性时间历程仿真、参数扰动与并发批量扫描。
重复执行、改变输出分块、分段求值与并发请求下结果一致且可解释。

## 运行

```bash
uv sync
uv run python main.py          # 启动 HTTP 服务 (127.0.0.1:8000)
uv run pytest                  # 全部测试，日志打印关键输入与判定依据
```

## 网络描述约定

网络为不可变数据结构（`app/models.py`），JSON 请求体示例：

```json
{
  "version": "model-1",
  "species": {"A": 1.0, "B": 0.0},
  "boundary_species": [],
  "reactions": [
    {
      "name": "r1",
      "reactants": {"A": 1},
      "products": {"B": 1},
      "rate":     {"kind": "mass_action", "params": {"k": 2.0}},
      "reverse":  {"kind": "mass_action", "params": {"k": 1.0}}
    }
  ]
}
```

- **物种**：`species` 给出名称与非负有限初始浓度；必须全部显式声明，不允许隐式创建。
- **反应**：`reactants` / `products` 为 `物种 -> 化学计量系数`，系数必须为有限正数；
  支持多底物、多产物和非 1:1 计量（如 `2A+B→C`、`A→B+C`）。
  可逆反应通过 `reverse` 速率律表达，其反应物为正反应的产物。
- **速率律**：
  - `mass_action`：参数 `k >= 0`，速率 `v = k·∏[反应物]^系数`；
  - `michaelis_menten`：参数 `kcat >= 0`、`Km >= 0`、`enzyme`（物种名字符串，
    不被消耗），速率 `v = kcat·[E]·[S]/(Km+[S])`，限定单底物。
- **闭合/开放网络**：`boundary_species` 为空即闭合网络，此时禁止源反应（`∅→X`）
  与汇反应（`X→∅`）；边界物种浓度恒定，开放网络允许源/汇。

### 物种组成（composition，可选）

可以为每个物种声明其由哪些原子/基团、各多少个组成：

```json
"composition": {
  "A": {"x": 1, "y": 1},
  "B": {"x": 1},
  "C": {"y": 1}
}
```

- 键为物种名（必须与 `species` 一一对应），值为 `组成项名称 -> 正的有限数量`。
  组成项名称是任意非空字符串（原子、基团均可），常见情况下为正整数；小数也按
  **精确有理数**处理（`0.1` 即 `1/10`，不产生浮点比较误差）。
- **全有或全无**：只要带了 `composition`，就必须为**每一个**物种声明；
  只声明一部分、为空映射、引用未声明物种、数量非正/非有限，一律报
  `INVALID_COMPOSITION`。
- 完全不带 `composition` 的网络视为老网络，行为与历史完全一致（见“兼容范围”）。

### 反应配平判定

带组成的网络，每个两侧都非空的反应都要在**每一个组成项**上精确配平，正、反两个
方向都核对；判定是精确的有理数等式，**没有数值容差、不会四舍五入、不会被自动修正**：

- 对组成项 `z`，左侧总量 `Σ 计量系数(物种) × 组成数量(物种, z)` 必须**等于**
  右侧同一组成项的总量。
- 任一组成项不等即报 `UNBALANCED_REACTION`，错误信息指明**反应名、方向
  （forward/reverse）、对不上的组成项、两侧精确总量以及逐物种贡献**，例如
  `reaction 'r1' forward is not balanced in component 'x': reactant side has 4
  [A(2) + B(2)], product side has 3 [C(3)]`，可直接定位到 `C` 的组成声明。
- 源反应（`∅→X`）与汇反应（`X→∅`）表示与环境交换物质，按定义不参与配平
  （闭合网络本来就禁止它们）；开放网络中两侧都非空的内部反应仍必须配平。

### 守恒量的含义与报告

闭合网络下，守恒检查围绕**网络自身的守恒量**进行。守恒量是化学计量矩阵的左零空间
基（精确整数加权和 `Σ wᵢ·[物种ᵢ] = 常数`），只取决于网络结构，与输出网格无关：

- 带组成时，每个原子/基团给出一条**有名字的守恒律**（`composition:x` …）；
  网络还可能存在组成之外的独立守恒量（如完全不参与反应的池），以
  `structural:n` 补齐；同一个网络的多条**彼此独立**的守恒量会分别报告。
- 不带组成的老网络直接给出结构零空间基（1:1 网络即为全部自由物种之和），
  因此 `2A+B→C` 这类平衡网络不再被旧的“全体浓度直接相加”误判为不守恒。
- 每条守恒量单独计算初始值、最大漂移
  `max|L(t)−L(0)|` 与容差 `conservation_tol · max(|L(0)|, 1)`（默认 `1e-6`）。
  **任何一条**超差即判 `CONSERVATION_VIOLATION`，错误信息列出超差守恒量的名字、
  权重、实际漂移与容差；未超差的量也会一并报告。
- 仿真结果 `trajectory.conservation_laws` 为逐量报告
  （`name/origin/weights/initial_value/max_deviation/tolerance/within_tolerance`）；
  老字段 `conserved_total` 与 `max_conservation_deviation` 保留：当“全部自由物种
  等权之和”本身是一条守恒量时取其值（历史 1:1 网络与旧实现逐位一致），否则取
  第一条守恒量作为摘要。
- 因为守恒量只由网络决定，输出步长变细、同一时间段拆开求值、并发请求都看到相同
  的守恒量与相同结论；ODE 只从 t=0 积分一次，输出仅对稠密解采样。

## 错误分类

错误**不会被静默修正或吞掉**，统一以 `422 {"code", "detail"}` 返回（离线调用抛
`NetworkValidationError` / `SimulationError`），不同原因代码可区分：

| code | 触发条件 |
| --- | --- |
| `MISSING_SPECIES` | 反应或速率律引用了未声明物种（含酶），或网络无物种、边界物种未声明 |
| `ILLEGAL_STOICHIOMETRY` | 计量系数非正/非有限，初始浓度为负/非有限，反应两侧皆空 |
| `INFEASIBLE_RATE` | 速率律类型未知、必需参数缺失、参数为负或非有限，或 ODE 求解失败 |
| `UNCLOSED_NETWORK` | 闭合网络中存在源或汇反应 |
| `INVALID_COMPOSITION` | 组成声明非法：引用未声明物种、有物种缺声明、组成项名为空、数量非正/非有限、空映射 |
| `UNBALANCED_REACTION` | 反应在某个组成项上不正反双向精确配平（信息含反应名、方向、组成项、两侧总量与逐物种贡献） |
| `CONSERVATION_VIOLATION` | 闭合网络任一独立守恒量偏离初值超过各自容差（信息含具体守恒量、权重、漂移与容差） |
| `NEGATIVE_CONCENTRATION` | 浓度低于 `-1e-9`（非物理负值） |
| `DUPLICATE_SPECIES` | 输入中存在重复边界物种条目 |
| `UNKNOWN_PARAMETER` | 扰动/扫描指定了不存在的反应或参数 |

`/validate`、`/simulate`、`/scan` 与离线批量扫描共用同一个
`validate_network()`，同一网络校验结论必然一致。

## 数值方法、容差与收敛判定

- ODE 用 LSODA（自适应刚性/非刚性），固定 `rtol=1e-9, atol=1e-12`，从 t=0
  积分一次并保留**稠密解**。输出网格（`n_points`）和时间分段只对同一稠密解
  采样，因此调小输出步长、把区间分段求值都不会改变轨迹与稳态结论。
- **守恒判定**：闭合网络对其**每一条独立守恒量**（化学计量矩阵左零空间的精确整数
  基；带组成时优先使用以组成项命名的守恒律）逐时刻计算加权和，最大偏差
  `max|L(t)−L(0)| ≤ conservation_tol · max(|L(0)|,1)`，默认容差 `1e-6`；
  任一条超限即抛 `CONSERVATION_VIOLATION`，错误信息点名超差的守恒量及其漂移、容差。
  守恒量由精确有理数（`fractions.Fraction`）高斯-若尔当消元导出，与浮点求解噪声无关。
- **非负判定**：求解器噪声范围内（≥ `-1e-9`）的微小负值在输出端钳为 0；
  低于该阈值抛 `NEGATIVE_CONCENTRATION`。
- **稳态结论**：在足够长的时间区间（如 20 个时间单位）末端读数；
  时间历程测试对解析平衡点（如可逆反应 kf/kr=2 时 [A]=1/3, [B]=2/3）校验。

## 隔离、复现、缓存键与兼容范围

- 网络与反应均为 frozen 数据结构；参数扰动（`perturb_parameter`）总是返回**新**
  网络，原对象不变。
- 每次扫描对每个参数值独立构建网络并仿真，无线程间可变共享；
  集成解缓存以网络全量描述（物种、计量、速率参数、边界集、`version`，以及
  **组成表（存在时）**）的 SHA-256 指纹加时间终点为键：相同请求逐位复现；
  **模型版本不同、任一速率参数不同，或物种名相同但组成不同，键都不同，结果
  不可能被错误复用**。缓存数组只读并用锁保护。
- `/scan` 与离线 `safe_scan_parameter` 做**单点失败隔离**：每个参数值独立返回
  `{"value", "ok", ...}`——成功点带独立 `fingerprint` 与 `trajectory`，失败点带
  `code` 与可定位的 `detail`（哪个值、哪个反应/组成项/守恒量），一个值建网或
  仿真失败不会中断其余值；并发扫描之间互不污染。
- **兼容范围**：不带 `composition` 的网络，请求格式、校验结论、指纹与结果与旧版
  完全一致（指纹的规范化载荷在无组成时不增加任何字节）；守恒检查内部升级为
  结构零空间基，但对历史 1:1 网络就是等权求和，数值结论不变。带组成的网络启用
  配平校验与命名守恒量，是纯增量能力。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查 |
| POST | `/validate` | 仅校验（含组成配平），返回 `{valid, fingerprint}` |
| POST | `/simulate` | 时间历程仿真，返回轨迹、逐守恒量漂移报告、最小浓度 |
| POST | `/scan` | 单参数批量扫描，每项 `ok` + 独立指纹/轨迹，或 `code`+可定位 `detail` |

## 验证方法（测试）

```bash
uv run pytest --log-cli-level=INFO
```

- `tests/test_validation.py`：10 类非法网络（缺失物种/酶、非法计量、不可行速率、
  未闭合网络等）各映射到独立 code，并逐例核对 HTTP 与离线校验结论一致。
- `tests/test_simulation.py`：闭合网络守恒、可逆反应平衡点、输出步长细化不变性、
  分段与一次求值一致性、非负性；通过注入轨迹确定性地触发
  `NEGATIVE_CONCENTRATION` 与 `CONSERVATION_VIOLATION`。
- `tests/test_scanning.py`：扰动不改原网络、同请求逐位复现、版本指纹隔离、
  8 轮 × 5 参数值的并发扫描互不污染且各有独立指纹。
- `tests/test_composition.py`（新增）：
  - 多底物（`2A+B→C`、`2A+3B+C→P`）与裂解（`A→B+C`）等非 1:1 计量的配平/不配平，
    可逆反应与开放网络源汇的配平边界；
  - 一个网络含多条彼此独立的守恒量（`x=A+B`、`y=A+C`）的分别报告与逐量漂移，
    以及仅超差的那一条被点名；网格细化、分段、16 路并发结论一致；
  - 组成声明矛盾/不合法（引用未声明物种、缺声明、零/负/非有限数量、空映射）报
    `INVALID_COMPOSITION`；
  - 不带组成的老网络指纹逐位不变、平衡点与守恒摘要照旧；老网络非 1:1 计量不再
    被误判；物种名相同但组成不同的网络指纹不同；
  - 参数扫描中单点失败（非法速率值、该点守恒漂移）只影响该点并带可定位原因，
    其余点正常，10 路并发扫描互不污染。
- `tests/test_api.py`：32 个并发 HTTP 请求轨迹逐元素一致、扫描指纹互不复用、
  错误信封机器可读；新增配平结论 HTTP/离线一致与命名守恒量报告断言。

每个测试用例均通过日志打印关键输入（网络/组成表/参数值/注入轨迹）与判定依据
（逐组成项总量、各守恒量漂移数值、指纹、比较结果），失败信息可直接定位到
原因 code 和具体反应/组成项/守恒量。
