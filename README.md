# 本地生化反应网络仿真服务

对本地生化反应网络做导入、校验、确定性时间历程仿真、参数扰动与并发批量扫描。
重复执行、改变输出分块、分段求值与并发请求下结果一致且可解释。

## 运行

```bash
uv sync
uv run python main.py          # 启动 HTTP 服务 (127.0.0.1:8000)
uv run pytest                  # 全部测试，日志打印关键输入与判定依据
```

## 网络描述约定

网络为不可变数据结构（`app/models.py`），JSON 请求体示例：

```json
{
  "version": "model-1",
  "species": {"A": 1.0, "B": 0.0},
  "boundary_species": [],
  "reactions": [
    {
      "name": "r1",
      "reactants": {"A": 1},
      "products": {"B": 1},
      "rate":     {"kind": "mass_action", "params": {"k": 2.0}},
      "reverse":  {"kind": "mass_action", "params": {"k": 1.0}}
    }
  ]
}
```

- **物种**：`species` 给出名称与非负有限初始浓度；必须全部显式声明，不允许隐式创建。
- **反应**：`reactants` / `products` 为 `物种 -> 化学计量系数`，系数必须为有限正数；
  支持多底物合成（如 `2A+B→C` 写作 `{"A": 2, "B": 1} → {"C": 1}`）与一底物裂解
  （如 `A→B+C`）；可逆反应通过 `reverse` 速率律表达，其反应物为正反应的产物。
- **组成（可选）**：`compositions` 为 `物种 -> {元素/基团 -> 个数}`，描述每个物种
  由哪些原子或基团、各多少个组成，例如 `{"A": {"C": 1, "H": 1}}`。规则：
  - **全有或全无**：要么所有物种都不声明组成（旧网络，行为与既往完全一致），
    要么每个已声明物种都必须有组成条目，缺一个即 `INVALID_COMPOSITION`；
  - 每个组成条目非空，元素名为非空字符串，个数为有限**正数**
    （0、负数、NaN 均报 `INVALID_COMPOSITION`）；为未声明物种写组成报 `MISSING_SPECIES`。
- **反应配平判定**：声明了组成的网络，对每个反应、每个元素逐项核对
  `Σ(反应物系数×组成) = Σ(产物系数×组成)`，相对容差 `1e-9`
  （`|lhs−rhs| ≤ 1e-9·max(|lhs|,|rhs|,1)`）。正/反向共用同一组计量，一次检查同时
  覆盖两个方向。不配平即 `UNBALANCED_REACTION`，错误信息给出**具体反应名、具体
  元素、两侧各自总量与差值**，不做任何自动修正。
- **速率律**：
  - `mass_action`：参数 `k >= 0`，速率 `v = k·∏[反应物]^系数`（多底物、非 1
    计量按幂次连乘）；
  - `michaelis_menten`：参数 `kcat >= 0`、`Km >= 0`、`enzyme`（物种名字符串，
    不被消耗），速率 `v = kcat·[E]·[S]/(Km+[S])`，限定单底物。
- **闭合/开放网络**：`boundary_species` 为空即闭合网络，此时禁止源反应（`∅→X`）
  与汇反应（`X→∅`）；边界物种浓度恒定，开放网络允许源/汇。

## 错误分类

错误**不会被静默修正或吞掉**，统一以 `422 {"code", "detail"}` 返回（离线调用抛
`NetworkValidationError` / `SimulationError`），不同原因代码可区分：

| code | 触发条件 |
| --- | --- |
| `MISSING_SPECIES` | 反应或速率律引用了未声明物种（含酶），或网络无物种、边界物种未声明、组成为未知物种声明 |
| `ILLEGAL_STOICHIOMETRY` | 计量系数非正/非有限，初始浓度为负/非有限，反应两侧皆空 |
| `INFEASIBLE_RATE` | 速率律类型未知、必需参数缺失、参数为负或非有限，或 ODE 求解失败 |
| `UNCLOSED_NETWORK` | 闭合网络中存在源或汇反应 |
| `INVALID_COMPOSITION` | 组成声明不合法或互相矛盾：部分物种缺组成、空组成、元素名非法、个数非有限正数 |
| `UNBALANCED_REACTION` | 反应对某元素不配平，信息含反应名、元素与两侧总量 |
| `CONSERVATION_VIOLATION` | 闭合网络某守恒量偏离初值超过容差，信息指明是哪一项 |
| `NEGATIVE_CONCENTRATION` | 浓度低于 `-1e-9`（非物理负值） |
| `DUPLICATE_SPECIES` | 输入中存在重复边界物种条目 |
| `UNKNOWN_PARAMETER` | 扰动/扫描指定了不存在的反应或参数 |

`/validate`、`/simulate`、`/scan` 与离线批量扫描共用同一个
`validate_network()`，同一网络校验结论必然一致。

## 数值方法、容差与收敛判定

- ODE 用 LSODA（自适应刚性/非刚性），固定 `rtol=1e-9, atol=1e-12`，从 t=0
  积分一次并保留**稠密解**。输出网格（`n_points`）和时间分段只对同一稠密解
  采样，因此调小输出步长、把区间分段求值都不会改变轨迹与稳态结论。
- **守恒判定**：守恒量围绕网络自身定义——声明了组成的网络，每个元素/基团
  就是一个独立守恒量（初值 `Σ(组成个数×浓度)`）；未声明组成的旧网络保持单一
  "total"（自由物种浓度之和）判定不变。闭合网络对每个守恒量分别计算最大漂移
  `max|Q(t)−Q(0)|`，容差 `conservation_tol · max(|Q(0)|,1)`（默认 `1e-6`）；
  **任何一项**超限即抛 `CONSERVATION_VIOLATION`，错误信息逐项列出名称、实际漂移
  与容差。仿真结果（`Trajectory.conservations` 与 HTTP 轨迹 JSON 的
  `conservations` 数组）逐项报告 `{name, initial, max_deviation, limit, passed}`；
  旧字段 `conserved_total` / `max_conservation_deviation` 保留。守恒检查在积分
  稠密解上进行，与输出网格无关，故调小输出步长、分段求值、并发请求下结论一致。
- **非负判定**：求解器噪声范围内（≥ `-1e-9`）的微小负值在输出端钳为 0；
  低于该阈值抛 `NEGATIVE_CONCENTRATION`。
- **稳态结论**：在足够长的时间区间（如 20 个时间单位）末端读数；
  时间历程测试对解析平衡点（如可逆反应 kf/kr=2 时 [A]=1/3, [B]=2/3）校验。

## 隔离、复现与缓存键

- 网络与反应均为 frozen 数据结构；参数扰动（`perturb_parameter`）总是返回**新**
  网络，原对象不变。
- 每次扫描对每个参数值独立构建网络并仿真，无线程间可变共享；
  集成解缓存以网络全量描述（物种、计量、速率参数、边界集、`version`，以及
  **声明了的组成**）的 SHA-256 指纹加时间终点为键：相同请求逐位复现；
  **模型版本不同、任一速率参数不同或组成不同则键不同，结果不可能被错误复用**。
  组成仅在声明时进入指纹，故不带组成的旧网络指纹与既往逐位一致；
  物种名相同但组成不同的两个网络必然得到不同指纹。缓存数组只读并用锁保护。
- **扫描单点失败隔离**：`/scan` 与离线 `scan_parameter_isolated` 对每个参数值
  独立建网、独立仿真。某个值建网或仿真失败（如扰动出负的速率常数）时，该点返回
  `{"value", "fingerprint", "error": {"code", "detail"}}`，其余点照常返回轨迹，
  整个请求仍为 200；不存在的反应名/参数名与取值无关，仍整体抛
  `UNKNOWN_PARAMETER`（HTTP 422）。并发扫描之间无共享可变状态，互不污染。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查 |
| POST | `/validate` | 仅校验（含组成配平），返回 `{valid, fingerprint}` |
| POST | `/simulate` | 时间历程仿真，返回轨迹、逐项守恒报告、最小浓度 |
| POST | `/scan` | 单参数批量扫描，每项含独立指纹；失败点带 `error` 不影响其余点 |

## 兼容范围

- 不带 `compositions` 的旧网络：请求格式、校验结论、守恒判定（单一 total
  守恒量）与结果指纹**逐位保持不变**；`compositions: {}` 与不写等价。
- 带组成的新网络：额外接受配平校验与逐元素守恒报告；组成进入指纹，
  组成不同的同名网络不复用缓存结果。
- 离线 `scan_parameter`（遇错即抛）行为不变；新增 `scan_parameter_isolated`
  提供逐点隔离语义，与 `/scan` 一致。

## 验证方法（测试）

```bash
uv run pytest --log-cli-level=INFO
```

- `tests/test_validation.py`：10 类非法网络（缺失物种/酶、非法计量、不可行速率、
  未闭合网络等）各映射到独立 code，并逐例核对 HTTP 与离线校验结论一致。
- `tests/test_simulation.py`：闭合网络守恒、可逆反应平衡点、输出步长细化不变性、
  分段与一次求值一致性、非负性；通过注入轨迹确定性地触发
  `NEGATIVE_CONCENTRATION` 与 `CONSERVATION_VIOLATION`。
- `tests/test_composition.py`：多底物（2A+B⇌C）与裂解（A→2B+C）非 1:1 计量网络的
  配平通过与仿真；不配平反应精确定位到反应名与元素；6 类非法/矛盾组成声明；
  双独立守恒量网络分别报告且违规信息指明超限量；输出网格细化与分段下守恒结论
  一致；旧网络指纹逐位兼容、同名不同组成网络指纹隔离；扫描单点失败（离线+HTTP）
  不影响其余点；8 轮并发扫描互不污染。
- `tests/test_scanning.py`：扰动不改原网络、同请求逐位复现、版本指纹隔离、
  8 轮 × 5 参数值的并发扫描互不污染且各有独立指纹。
- `tests/test_api.py`：32 个并发 HTTP 请求轨迹逐元素一致、扫描指纹互不复用、
  错误信封机器可读。

每个测试用例均通过日志打印关键输入（网络/参数值/注入轨迹）与判定依据
（偏差数值、指纹、比较结果），失败信息可直接定位到原因 code 和具体反应/物种。
